# Syed Abdul Samad Ahsan — Portfolio

Responsive portfolio built with HTML, CSS, and JavaScript. No dependencies or build step required.

## Local preview
Open `dist/index.html` in your browser.

## Vercel deployment
Import this repository into Vercel, select framework **Other**, leave the build command empty, and use **dist** as the output directory. The included `vercel.json` configures the output directory.

## Customization
Edit `dist/index.html`. Contact details are intentionally a placeholder. ShopCo artwork is illustrative, not a screenshot.
